Backup e ripristino Purchasing

Solo amministratori
Apri Impostazioni → Backup. La funzione opera sul database Purchasing del backend condiviso.

Creare un backup

  1. Assicurati che salvataggi e aggiornamenti in corso siano terminati.
  2. Apri Backup e premi Crea backup.
  3. Attendi il messaggio “Backup creato” con nome o percorso.
  4. Annota data, motivo e versione dell'app se il backup precede un aggiornamento importante.

Ripristinare

  1. Premi Ripristina backup e conferma che il database corrente verrà sostituito.
  2. L'app recupera dal server l'elenco dei backup disponibili.
  3. Inserisci esattamente il nome di quello desiderato.
  4. Attendi “Ripristino completato”: le viste vengono ricaricate automaticamente.
  5. Verifica una richiesta acquisto, un intervento e una voce catalogo prima di riprendere il lavoro.
Operazione distruttiva
Il ripristino sostituisce lo stato corrente. Crea prima un nuovo backup se potrebbero servire le modifiche più recenti e avvisa gli altri operatori collegati.

Cosa controllare in caso di errore

  • Nessun backup disponibile: non è mai stato creato un backup sul server corrente oppure il backend usa un'altra cartella dati.
  • Nome non trovato: copiare il nome completo mostrato, senza aggiungere spazi.
  • Errore server: annotare messaggio, orario, nome backup e server utilizzato.
  • Dati apparentemente vecchi: premere Aggiorna e verificare che gli altri client abbiano ricevuto il riallineamento.
